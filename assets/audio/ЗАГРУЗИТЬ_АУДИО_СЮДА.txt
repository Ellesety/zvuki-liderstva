ЗВУКИ ДЛЯ КНОПОК «СЛУШАТЬ ЭПОХУ»
================================
Положите сюда файлы с ТОЧНО такими именами (маленькие буквы, без пробелов):

  yohanan.mp3      -> история 1: Йоханан бен Закай
  herzl.mp3        -> история 2: Теодор Герцль
  ben-gurion.mp3   -> история 3: Давид Бен-Гурион

Подойдут также .wav, .ogg или .m4a с тем же именем (например herzl.wav).
Если файла нет, сайт не ломается и пишет «Audio file not added yet».
Рекомендуется: до 3 МБ на файл, 30-90 секунд (звук зациклен).
Используйте только звуки, на которые у вас есть права.
