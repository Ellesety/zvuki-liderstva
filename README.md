# Звуки лидерства

Статический сайт: HTML + CSS + Vanilla JS. Без сервера, без библиотек.

## 1. Как открыть локально
Откройте `index.html` двойным кликом. Если браузер блокирует аудио — запустите `python3 -m http.server` в папке и откройте `http://localhost:8000`.

## 2. Как заменить текст
Весь контент — в начале `script.js`: `PROJECT`, `STORIES`, `QUIZ`. Ищите комментарии `// CHANGE THIS TEXT`.

## 3. Как добавить изображение
Положите файл в `assets/images/` и укажите путь в `image` нужной истории (`assets/images/herzl.jpg`). Если файла нет, показывается заглушка.

## 4. Как добавить MP3
Положите файл в `assets/audio/` (`yohanan.mp3`, `herzl.mp3`, `ben-gurion.mp3`) или измените путь в поле `audio`. Используйте только звуки, на которые у вас есть права. Если файла нет, сайт покажет «Audio file not added yet».

## 5. Как заменить лидера
В объекте истории поменяйте `leader`, `year`, `hook`, `context`, `options`, `quality`, `quote`, `image`, `audio`.

## 6. Как добавить эпоху
Скопируйте один объект в `STORIES`, поменяйте `id` (латиницей, уникальный) и содержимое. Кнопка в меню и раздел создадутся сами.

## 7. GitHub Pages
1. Создайте репозиторий на github.com и загрузите все файлы (`index.html` в корне).
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПО/`.

## 8. Что нельзя переименовывать
`index.html`, `style.css`, `script.js`, `favicon.svg` и папку `assets/`. Не добавляйте `/` в начале путей: используйте `assets/audio/herzl.mp3`.

## 9. Как исправить путь
Проверьте регистр букв и расширение: `Herzl.MP3` ≠ `herzl.mp3`. Пути в `script.js` относительные.

## 10. Как обновить сайт
Замените файлы в репозитории (Add file → Upload files → Commit). Обновление появится через минуту; обновите страницу с Ctrl+F5.

## Важно
Все `[ADD SOURCE]`, `[ADD VERIFIED QUOTE]` и `[SOURCE NEEDED]` — места, где нужна проверка. Не публикуйте цитаты без источника.
